\# Python Real-Time Chat Application



\## OIBSIP Python Programming Internship - Task 5



A real-time multi-user chat application developed in Python using socket programming, Tkinter GUI, threading, and SQLite.



\## Features



\- User registration and login

\- Real-time bidirectional messaging

\- Multiple simultaneous clients

\- Multiple chat rooms

\- Create and join chat rooms

\- Automatic room synchronization

\- Room-specific messaging

\- Message timestamps

\- SQLite message history

\- Emoji support

\- Client-server architecture

\- Graceful connection handling

\- Graphical user interface using Tkinter



\## Technologies Used



\- Python

\- Socket Programming

\- Tkinter

\- SQLite

\- Threading

\- datetime
