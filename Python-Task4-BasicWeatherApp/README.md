\# 🌦️ Basic Weather App



A Python-based desktop weather application developed as part of the \*\*Oasis Infobyte Python Programming Internship\*\*.



The application uses the \*\*OpenWeatherMap API\*\* to fetch and display real-time weather information for a user-specified city.



\## 📌 Task Details



\- \*\*Internship:\*\* Oasis Infobyte

\- \*\*Track:\*\* Python Programming

\- \*\*Task:\*\* Task 4 - Basic Weather App



\## ✨ Features



\- Search weather by city name

\- Real-time weather data using OpenWeatherMap API

\- Current temperature in Celsius/Fahrenheit

\- Feels-like temperature

\- Humidity

\- Wind speed

\- Atmospheric pressure

\- Weather condition and description

\- Weather icons from OpenWeatherMap

\- Next 6 hours weather information

\- 5-day forecast

\- Celsius/Fahrenheit toggle

\- Enter key support for searching

\- Empty input validation

\- Handles invalid city names

\- Handles invalid API keys

\- Handles network and timeout errors

\- Error messages are displayed inside the GUI

\- Responsive GUI using background threads



\## 🛠️ Technologies Used



\- Python

\- Tkinter

\- Requests

\- JSON

\- Pillow (PIL)

\- python-dotenv

\- OpenWeatherMap API
